# reusable-studio-engine
This engine's purpose is to make a project template for file organization and general project setup in the future, while also providing a neat and fun little canvas to go off of to show it works.
To run locally (not on-site but off local files), make a simple local host at http://localhost:8000 or open the index.html file.
Personally, I chose to deploy the engine on GitHub.
How I use this to start projects is have a base of files to go off of that I can simply copy and paste without needing to worry about what files I need to make.
